# 📊 Sales Performance Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive **Sales Performance Dashboard** built in **Microsoft Excel** to analyze sales data across different cities and sales executives. The dashboard provides insights into **sales performance, target achievement, and regional trends** using Pivot Tables, Pivot Charts, and Slicers.

---

## 🚀 Features

* Interactive dashboard with **Slicers** for dynamic filtering.
* Sales analysis by **City** and **Sales Executive**.
* Target achievement analysis using **Target Hit %**.
* KPI cards displaying:

  * Total Sales
  * Average Target Hit %
* Dynamic Pivot Charts for better data visualization.
* Easy-to-use interface for exploring sales performance.

## 📈 Dashboard Insights

The dashboard helps answer business questions such as:

* Which city generated the highest sales?
* Which sales executive achieved the highest sales?
* What percentage of the sales target was achieved?
* How does sales performance vary across different regions?
* Which executives require performance improvement?
